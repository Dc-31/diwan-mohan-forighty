# दिवान मोहन फोर्टी

A modern, responsive Hindi newspaper landing page for **दिवान मोहन फोर्टी**, a fortnightly newspaper published from Ajmer, Rajasthan since 1984.

## Features

- Responsive editorial layout for desktop, tablet, and mobile
- Hindi-first typography using Noto Sans Devanagari
- Sections for Ajmer, Rajasthan, India, World, editorial, and culture
- Mobile navigation menu
- Newsletter subscription interaction
- Accessible labels and semantic HTML
- No build step required — open `index.html` directly or deploy to GitHub Pages

## Run locally

Open `index.html` in a browser. The site loads its fonts from Google Fonts when online.

## Deploy

This is a static site and can be deployed with GitHub Pages by selecting the `main` branch as the publishing source in repository Settings → Pages.
